# Portfolio 3D

Site portfolio responsive (PC + mobile) avec scène 3D Three.js (blob shader, anneaux, particules), animations au scroll, tilt 3D, curseur custom.

## Lancer
Ouvrir `index.html` (aucun build nécessaire) ou `npx serve .`

## Personnaliser
- Nom, textes, projets, compétences : `index.html`
- Email de contact : `js/main.js` (`TO`) et `index.html`
- Couleurs : variables CSS dans `css/style.css`
- Scène 3D : `js/scene.js`
